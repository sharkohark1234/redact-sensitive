redact-sensitive

Redact emails, phone numbers, API keys, credit cards and other sensitive data from text and logs — before they leave your app.

Zero dependencies. Node.js 16+. TypeScript types included.

View on GitHub View on npm Try the interactive playground

Install

npm install redact-sensitive

Try it

const { redact } = require('redact-sensitive');

redact('Contact me at ana@example.com or 555-123-4567');
// 'Contact me at [EMAIL] or [PHONE]'

redact('Card 4111 1111 1111 1111, api_key = abc123secret');
// 'Card [CARD], api_key = [API_KEY]'

Why

Logs, error reports and support tickets routinely leak the data they were meant to debug. One console.log(user) can put an email, a token or a card number into a log store. This library is a one-line safety net: run untrusted text through it before logging, storing or sending it anywhere.
